# Product roadmap

The direction is a more useful restaurant website with the existing Bruxx
content and identity. Changes should shorten a guest’s path to food, a booking
or a visit; factual claims continue to come from the restaurant.

## Delivered

- [x] Czech, English and German routes, responsive layouts and light/dark themes.
- [x] Live menu with snapshots, search, categories and allergen filters.
- [x] Beer finder, photo gallery, recipes and family information.
- [x] Mobile header booking, direct booking fallback and reservation deep links.
- [x] Quick lunch, beer and directions links on the home page.
- [x] Independent freshness labels for lunch, dishes and beer.
- [x] Clear no-results recovery and deliberate newsletter consent.
- [x] Links to current restaurant events and children’s menu prices.
- [x] Content map, maintenance guide and publication checklist.

## Next improvements

1. **Children’s menu inside the family page.** The current source has a full
   children’s menu, while this site links to it. Establish a maintainable source
   and display dishes, portions and prices with explicit freshness, without
   copying prices into permanent prose. Done when a parent can choose a meal
   without leaving the page and an unavailable source has a useful fallback.
2. **Shareable filtered menus.** Store menu search and selected allergen filters
   in the URL, preserve them across language changes and provide a clear reset.
   Done when a guest can copy a link and recover the same selection after reload.
3. **Seasonal events with dates.** Replace illustrative themes with an approved
   structured source. Show an event only while its dates apply; retain a useful
   off-season view. Do not infer dates from old promotional images.

## Restaurant launch decisions

- Approve German translation and confirm lunch hours and holiday exceptions.
- Confirm photo/content rights for the final domain and the final privacy text.
- Verify Bookio and Menubot end-to-end using approved test arrangements.
- Decide old URL redirects, canonical domain and indexing policy.
- Consider a first-party menu feed to remove the runtime third-party script dependency.

These are launch dependencies, not claims that the preview already replaces the
restaurant’s production website.
